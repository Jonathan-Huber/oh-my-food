# oh-my-food

## Description

Ce projet fait partie de ma formation d'intégrateur web chez OpenClassrooms.  
L’objectif est d’intégrer l’interface mobile-first du site d’une start-up, en utilisant **Sass** pour les styles, des **animations CSS**, et un système de **gestion de version avec Git et GitHub**.

## Compétences visées

- Intégration mobile-first (responsive design)
- Utilisation de Sass pour le CSS
- Création d’animations avec CSS
- Versionnage du projet avec Git et GitHub

## Technologies

- HTML5  
- CSS3 / Sass  
- Git / GitHub
